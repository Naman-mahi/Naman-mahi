## 🚀 About Me

I am a software engineer with a hacker mindset and a passion for machine intelligence. Currently pursuing my **Master's in Cybersecurity**, I bridge the gap between intelligent AI systems, robust full-stack architecture, and offensive/defensive security.

- 🧠 **Artificial Intelligence & ML**: Training models with PyTorch, TensorFlow, and Scikit-learn for anomaly detection, NLP, and intelligent automation.
- 🛡️ **Cybersecurity & Ethical Hacking**: Penetration testing, vulnerability assessments, and red-team operations using Kali Linux, Metasploit, Burp Suite, and Wireshark.
- 💻 **Full-Stack Engineering**: Architecting responsive web applications with React, TypeScript, Node.js, Python, and SQL/NoSQL databases with security-first design patterns.
- 🎨 **Modern UI/UX**: Dedicated to clean dark-mode interfaces, smooth micro-interactions, and high performance.
- 📍 **Location**: Gondia, Maharashtra, India 🇮🇳
- ☕ **Fuel**: Coffee + Curiosity + Late-night debugging
- 🎯 **Mission**: Merging **AI + Cybersecurity** to build resilient, next-generation technology.
