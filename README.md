## 🧭 Core Focus & Capabilities

- 🧠 **Applied Artificial Intelligence**: Architecting neural networks with PyTorch, TensorFlow, and Scikit-learn for time-series telemetry classification, semantic NLP matching, and intrusion detection.
- 🛡️ **Cybersecurity & Pen-Testing**: Conducting vulnerability assessments, packet inspections, and web exploit mitigations (OWASP Top 10) utilizing Kali Linux, Metasploit, Burp Suite, and Wireshark.
- ⚡ **Full-Stack Web Engineering**: Building scalable, reactive client-server architectures using React, TypeScript, Node.js, Express, Python (FastAPI/Flask), and relational/NoSQL datastores.
- 🔒 **Security-First Architecture**: Implementing robust OAuth2/JWT auth cycles, cryptographic encryption, rate limiting, and zero-trust containerized microservices.
